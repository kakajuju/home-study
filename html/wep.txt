1. 웹의 기본 동작 원리 알아보기

클라이언트(Client) - 손님

서버(Server) - 카페 주방

IP 주소 - 카페 주소

포트번호 - 주문받는 카운터

URL - 메뉴를 찾는 정보

웹 브라우저 - 키오스크

- 작동 방식
1. 손님 (클라이언트) - 아메리카노 주문
2. 메뉴판 (웹 브라우저) - URL 확인 및 요청 준비
3. 카페 위치 및 주문 창구 - DNS → IP 주소 → 포트번호
4. 카페 직원과 주방 (서버) - HTTP / HTTPS로 주문 전달 및 처리
5. 완성된 아메리카노 (응답 데이터) - 브라우저에 결과 표시
